# Online Book Store

An **online book-selling web application** built with the **MERN stack (MongoDB, Express.js, React.js, Node.js)**. This application allows users to browse, search, and purchase books online.
Admins can manage the book catalog, track orders, and update inventory.

---

## Features

### User Features
- Browse and search books by category, title, or author.
- View book details including description, price, and availability.
- Add books to the shopping cart.
- User registration and authentication.
- View order history and track order status.

### Admin Features
- Add, update, or delete books in the catalog.
- Manage user orders and track deliveries.

---

## Tech Stack

- **Frontend:** React.js, Redux, Tailwind CSS / Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Tokens)
